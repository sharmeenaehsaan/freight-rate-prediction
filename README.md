# Freight Rate Prediction Challenge

## Overview

This project predicts freight rates for transportation loads using historical load data.

The solution uses **CatBoost Regression** with a **log-transformed target (`log1p`)** to model posted freight rates. The model uses route, distance, equipment, load, market, quote, and date-related features.

The final model is trained on the complete development dataset and is used to generate predictions for the provided validation dataset and the fixed December chart dataset.

## Dataset

The development dataset contains **48,000 loads** with the target variable:

```text
posted_rate
```

The validation dataset contains **12,000 loads** without the target value.

Important input features include:

* Pickup location
* Delivery location
* Pickup latitude and longitude
* Delivery latitude and longitude
* Distance
* Equipment type
* Weight
* Date
* Market index
* Quote signal

The validation dataset contains the same predictive features but does not contain `posted_rate`.

---

## Data Preprocessing

The following preprocessing steps were applied:

### Missing Values

Missing values in numerical features were handled using medians calculated from the relevant training data.

### Weight Cleaning

Negative weight values were treated as sign errors and converted using their absolute values.

```text
weight = abs(weight)
```

### Date Features

The original date was converted into:

* Year
* Month
* Day
* Day of week
* Day of year

### Route Feature

A combined route feature was created:

```text
pickup -> delivery
```

This allows the model to learn differences between individual freight lanes.

## Model Development

Several experiments were performed before selecting the final approach.

The experiments included:

* Baseline CatBoost regression
* Comparison with and without geographic distance
* Log-transformed target modeling
* Weighted training for high-rate loads
* Route-history based features
* High-rate and extreme-rate analysis
* Multi-stage modeling experiments

The final approach was selected based on validation performance during development.

### Selected Model

The final model uses:

**CatBoost Regression + Log1p Target Transformation**

The target transformation is:

```python
y_log = np.log1p(posted_rate)
```

Predictions are converted back to the original rate scale using:

```python
predicted_rate = np.expm1(prediction)
```

### Model Parameters

```text
Model: CatBoostRegressor
Iterations: 282
Learning rate: 0.05
Depth: 8
Loss function: RMSE
Random seed: 42
```

Categorical features include:

* `pickup`
* `delivery`
* `equipment`
* `route`

## Development Validation

During model development, an 80/20 random split was used.

The split contained:

```text
Training rows:   38,400
Validation rows:  9,600
```

The split was stratified with respect to extreme high-rate observations.

The selected Log1p CatBoost model achieved:

```text
MAE:  $93.15
RMSE: $588.71
R²:   0.8461
```

These are **internal development validation metrics** and are not the final competition/assessment scores.

The provided final validation dataset does not contain the actual `posted_rate`, so local MAE/RMSE/R² cannot be calculated for those 12,000 loads.

## Final Model Training

After selecting the modeling approach, the final CatBoost model was retrained using all **48,000 development rows**.

The trained model is saved as:

```text

```

The final model is used to predict the 12,000 validation loads.

## Limitations

The development data contains a small number of extreme high-rate observations. These observations are difficult to predict accurately using the available structured features.

The selected model performs substantially better on the majority of ordinary-rate loads than on the rare extreme-rate cases.

The final 12,000 validation records do not contain `posted_rate`, so their actual prediction error cannot be calculated locally. The official assessment system calculates the final validation performance after submission.
